# 🏥 AI Healthcare — CareAI

An AI-powered healthcare platform designed to help users explore healthcare services, discover doctors and nearby hospitals, access medicine information, and make more informed wellness decisions.

## ✨ Features

* 🩺 **Healthcare Guidance** — Explore health information and specialist recommendations.
* 🏥 **Nearby Hospitals** — Find healthcare facilities and access location information.
* 🩻 **CT Scan Centers** — Explore nearby diagnostic imaging facilities.
* 👨‍⚕️ **Doctor Portal** — Demo doctor dashboards and appointment management.
* 👤 **Patient Portal** — Patient dashboard with sample health and appointment information.
* 💊 **Medicine Information** — Search common medicines and learn about their uses and precautions.
* 🥗 **Health & Nutrition** — Condition-based food guidance, BMI calculator, protein guidance, and nutrient information.
* 🍽️ **AI Meal Assistant** — Explore meal ideas based on dietary preferences and wellness goals.
* 💧 **Hydration & Fitness** — Track water intake and explore general activity and wellness guidance.
* 📊 **Progress Tracking** — View wellness-related progress where supported by the application.
* 🔐 **Authentication** — Uses the application's configured authentication system.

## 🛠️ Tech Stack

* React
* TypeScript

## 🚀 Run Locally

### Prerequisites

Install Node.js and npm.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/25B13CD058/Health_care_AI.git
   ```

2. Enter the project directory:

   ```bash
   cd Health_care_AI
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables using the provided `.env.example` file, if applicable. Never commit private API keys or secrets.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in your terminal, usually `http://localhost:3000` or another available port.

### Production Build

```bash
npm run build
```

## ⚠️ Medical Disclaimer

CareAI provides healthcare information for educational and general wellness purposes. It is not a substitute for professional medical advice, diagnosis, or treatment.

Always consult a qualified healthcare professional for medical decisions. Do not start, stop, or change medication based solely on information displayed by this application.

Nearby facility availability, services, ratings, and contact details should be verified directly with the relevant provider.

## 🔒 Privacy & Security

Do not submit real medical information when using a demonstration account. Keep environment variables, credentials, and API secrets private.
